🔌 Arduino Serial Monitor Web

ℹ️ Cara Menggunakan:

Aplikasi ini menggunakan Web Serial API untuk berkomunikasi dengan Arduino:

  • Klik "Connect Arduino" - Browser akan menampilkan dialog untuk memilih port serial
  • Pilih port Arduino Anda (biasanya bernama USB Serial Device atau COM port)
  • Data akan ditampilkan secara otomatis di memo dan grafik
  • Klik "Save Data" untuk mengunduh data ke file txt

Catatan: Web Serial API hanya bekerja di browser Chrome, Edge, atau Opera versi terbaru dengan protokol HTTPS atau localhost.
